# Handover: claude-backend

Phases 1 through 3 are complete. The backend works end to end: the live test
`uv run pytest -m live -k claude` passes against the real installed CLI.

Phase 4 is next and is documentation only: `CLI_ARGUMENTS.md` and `README.md`.

Phase order is adapter, driver wiring, direct-invocation API, documentation.

claude target to the pi adapter.

CLI facts were verified live against `claude` 2.1.220 on 2026-08-24. Re-verify
with `claude --help` before implementing if the CLI has been upgraded since.
