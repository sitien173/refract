# Handover: claude-backend

Complete. All four phases are done and the backend works end to end. The live
test `uv run pytest -m live -k claude` passes against the real installed CLI.

Phase order was adapter, driver wiring, direct-invocation API, documentation.
Phases 2 and 3 each removed a bare `else` dispatch that would otherwise have
routed a claude target to the pi adapter.

Phase 4 was executed directly rather than routed, because
`coordinating-multi-model-work` excludes documentation work from OpenMCP
routing. It therefore has no independent quality review.

CLI facts were verified live against `claude` 2.1.220 on 2026-08-24. Re-verify
with `claude --help` before implementing if the CLI has been upgraded since.

worker environment. Phase 1's worker reported false debt over this.
